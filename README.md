# 3D 蛋白质结构与配体结合可视化平台

React + Vite + TypeScript + React Three Fiber 的结构生物学可视化基础项目，用于展示蛋白质骨架、关键残基、配体原子和结合口袋关系。

## 当前能力

- **多构象结构对比**：同一蛋白的多个构象在同一坐标系中叠合显示，每个构象独立控制显示 / 透明度 / 颜色
- 构象列表切换当前分析对象；残基与配体选择、相互作用结果、右侧详情及结合口袋指标均归属于当前构象
- 构象缺失某残基或配体时不渲染、不替代坐标，详情面板明确提示缺失；删除当前构象后自动选出稳定后继，全部删除后进入可恢复的空场景
- 支持复制当前构象（自动施加可区分的坐标微扰），以及粘贴 JSON / PDB（ATOM / HETATM）录入新构象
- 卡通带状、表面模型、原子视图切换
- 关键残基选择与空间定位、配体原子点击选择、配体旋转
- 残基角色、空间坐标、实测距离（缺失时显示 —）与作用类型展示
- 结合口袋指标（体积 / 结合残基数 / 氢键数）按当前构象实时计算

## 录入格式

JSON（残基为世界坐标，配体原子为配体局部坐标；未列出的残基 / 原子视为缺失）：

```json
{"name":"构象 D","residues":{"41":[-1.6,0.4,0.5],"78":[-0.7,1.15,-0.25]},"ligand":{"present":true,"atoms":{"N1":[0.98,-0.18,0.18]}}}
```

PDB：粘贴 `ATOM`（CA）/ `HETATM` 记录，坐标自动居中并缩放到示例场景量级。

## 启动

```bash
npm install
npm run dev
```

当前使用内置示例结构数据（构象 A 完整、构象 B 缺失 HIS102 与 S1、构象 C 为 apo 态），后续可接入真实原子键推断、分子对接结果、氢键几何筛选和结构比对。
