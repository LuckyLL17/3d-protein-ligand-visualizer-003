# 3D 蛋白质结构与配体结合可视化平台

React + Vite + TypeScript + React Three Fiber 的结构生物学可视化项目，用于展示蛋白质骨架、关键残基、配体原子和结合口袋关系。

## 当前能力

- **多构象结构工作区**：加载或录入同一蛋白的多个结构构象（开放态 / 闭合态 / 无配体 Apo / 突变体）
- 每个构象在 3D 视图中独立控制**显示 / 隐藏、透明度、颜色**，可叠加对比
- 从构象列表切换当前分析对象；在 3D 中点击任一构象的残基或原子也会自动把所属构象设为当前
- 残基 / 配体选择、相互作用结果、右侧详情与指标**明确属于当前构象**（面板标注构象名与 PDB 代码）
- 构象缺少某个残基或配体时：数据中真实缺席，详情显示"未解析"缺失状态，**不会用其它构象的坐标顶替**
- 删除当前构象时按"后继优先、末尾取前驱"选出稳定后继；删除全部构象后 3D 场景仍可渲染并可一键恢复
- 卡通带状、表面模型、原子视图切换
- 关键残基选择与空间定位、配体原子点击、配体旋转
- 结合口袋指标、残基角色、空间坐标、配体距离与作用类型展示

## 启动

```bash
npm install
npm run dev
```

模型层不变量自检：

```bash
npx esbuild scripts/check-model.ts --bundle --platform=node --format=esm --outfile=/tmp/check-model.mjs && node /tmp/check-model.mjs
```

当前使用内置示例结构数据，后续可接入 PDB/mmCIF 文件解析、真实原子键推断、分子对接结果、氢键几何筛选和结构比对。
